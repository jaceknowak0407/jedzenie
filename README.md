# Jedzenie do pracy

Prosta aplikacja (PWA) do planowania jedzenia na zimno do pracy: przepisy, plan tygodnia, zamrażarka, produkty w domu, lista zakupów i notatki.

- Przepisy: `przepisy.json`
- Dane użytkownika (oceny, plany, produkty) zostają tylko w telefonie (localStorage) — nic nie jest wysyłane na serwer.
